# Arha Dental Care: demo website

A static demo site (HTML, one CSS file, one small vanilla JS file, no build step).
It is kept out of search engines (`noindex`, `robots.txt Disallow: /`) until launch.

## Run locally

```bash
python -m http.server 8080
# open http://127.0.0.1:8080/
```

## Structure

```
index.html                         Home
dental-implants/ before-after/ book/   Inner pages (generated by tools/pages.py)
assets/css/site.css                All styles
assets/js/site.js                  All behaviour
assets/fonts/ img/ logo/ video/    Self-hosted fonts and media
tools/                             Asset pipeline and page builder (Python)
```

Inner pages are generated from the homepage's shared header, menus and footer plus the templates in
`tools/pages/`:

```bash
python -m venv .venv && .venv/Scripts/python -m pip install -r tools/requirements.txt
.venv/Scripts/python -I tools/pages.py && .venv/Scripts/python -I tools/cases_markup.py
```

Contact details, opening hours and the Riya webhook live in one place, `SITE` in `tools/pages.py`.
Change them there and run the two commands above; every page, link, the call QR code and `site.js` follow.

Fonts: D-DIN, Jost and Cormorant Garamond (SIL Open Font License, licences in `assets/fonts`).
Demo imagery includes licensed stock photography and video (Unsplash, Pexels).
