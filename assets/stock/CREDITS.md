# Stock images (demo only)

Every image in this folder is a **sample for the demo**. None of these people are Arha's patients. Each "Smile results"
card is tagged "Sample" on the site. Replace them with Arha's own cases, shared with patient consent, before launch.

How they are made (`tools/samples.py`): both sides of a pair are the **same photograph**. The "before" has a gentle
simulated shade added to the teeth, so the slider lines up exactly. No teeth were reshaped.
